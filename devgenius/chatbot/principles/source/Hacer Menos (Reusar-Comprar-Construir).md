# Hacer Menos (Reusar-Comprar-Construir)

## Declaración

Las decisiones arquitectónicas deben seguir la jerarquía estratégica: reutilizar componentes existentes para lograr eficiencia, adquirir soluciones comerciales (COTS) para funcionalidades estándar y construir únicamente aquellas capacidades que generen una ventaja competitiva diferenciadora en el mercado bancario, siempre que el caso de negocio lo justifique.

## Descripción

Tomar decisiones de arquitectura considerando el tiempo de salida al mercado (time-to-market), el costo total de propiedad (TCO) y la diferenciación estratégica.

## Alcance

Todas las nuevas soluciones tecnológicas y modernización de sistemas existentes.

## Beneficios

1. Reducción de costos de desarrollo
2. Aceleración de time-to-market
3. Optimización de recursos técnicos
4. Mejora en calidad y estabilidad

## Atributos ISO 25010

1. Eficiencia de desempeño
2. Mantenibilidad
3. Eficiencia de desempeño
4. Disponibilidad

## Métricas

1. Porcentaje de reutilización de componentes
2. Reducción de tiempo de desarrollo
3. Tiempo de implementación de nuevas funcionalidades
4. Velocidad de integración COTS
5. Reducción de deuda técnica
6. Reducción de defectos en componentes reutilizados
7. Disponibilidad de soluciones COTS
