## 1. Resumen Ejecutivo

### 1.1 Propósito del Sistema

Sistema de detección proactiva de anomalías en logs de aplicaciones mediante Machine Learning no supervisado, capaz de predecir caídas antes de que ocurran.

### 1.2 Especificaciones Clave

| Métrica | Valor |
|---------|-------|
| Volumen de datos | 5TB/día |
| Latencia de detección | 5-10 minutos |
| Retención en streaming | 7 días |
| Throughput | 58+ MB/s |
| Disponibilidad objetivo | 99.9% |
| Costo mensual estimado | $1,000-1,500 |

### 1.3 Beneficios

- **Detección temprana**: Identificación de anomalías 5-15 minutos antes de fallos críticos
- **Reducción de MTTR**: Disminución del tiempo de resolución en 60-70%
- **Automatización**: Eliminación de monitoreo manual 24/7
- **Escalabilidad**: Procesamiento automático de crecimiento de logs

#### 3.2.2 Código de Extracción de Features

```python
import json
import boto3
from datetime import datetime
from collections import defaultdict
import base64

s3_client = boto3.client('s3')

class FeatureExtractor:
    def __init__(self):
        self.features = defaultdict(lambda: {
            'error_count': 0,
            'total_requests': 0,
            'latency_sum': 0,
            'latency_max': 0,
            'http_5xx': 0,
            'http_4xx': 0,
            'http_2xx': 0,
            'cpu_usage_sum': 0,
            'memory_usage_sum': 0,
            'unique_errors': set()
        })
    
    def extract(self, log_entry):
        """Extrae features de un log individual"""
        try:
            timestamp = log_entry.get('timestamp')
            window_key = self._get_window_key(timestamp)
            
            # Contadores básicos
            self.features[window_key]['total_requests'] += 1
            
            # Errores
            if log_entry.get('level') == 'ERROR':
                self.features[window_key]['error_count'] += 1
                error_msg = log_entry.get('message', '')
                self.features[window_key]['unique_errors'].add(error_msg[:100])
            
            # Latencia
            latency = log_entry.get('latency_ms', 0)
            self.features[window_key]['latency_sum'] += latency
            self.features[window_key]['latency_max'] = max(
                self.features[window_key]['latency_max'], 
                latency
            )
            
            # HTTP Status Codes
            status_code = log_entry.get('status_code', 0)
            if 500 <= status_code < 600:
                self.features[window_key]['http_5xx'] += 1
            elif 400 <= status_code < 500:
                self.features[window_key]['http_4xx'] += 1
            elif 200 <= status_code < 300:
                self.features[window_key]['http_2xx'] += 1
            
            # Recursos
            self.features[window_key]['cpu_usage_sum'] += log_entry.get('cpu_percent', 0)
            self.features[window_key]['memory_usage_sum'] += log_entry.get('memory_mb', 0)
            
        except Exception as e:
            print(f"Error extracting features: {e}")
    
    def _get_window_key(self, timestamp):
        """Genera clave de ventana de 5 minutos"""
        dt = datetime.fromisoformat(timestamp.replace('Z', '+00:00'))
        window_start = dt.replace(minute=(dt.minute // 5) * 5, second=0, microsecond=0)
        return window_start.isoformat()
    
    def compute_aggregated_features(self):
        """Calcula features agregadas por ventana"""
        result = {}
        for window_key, metrics in self.features.items():
            total = metrics['total_requests']
            if total == 0:
                continue
            
            result[window_key] = {
                'timestamp': window_key,
                'error_rate': metrics['error_count'] / total,
                'avg_latency': metrics['latency_sum'] / total,
                'max_latency': metrics['latency_max'],
                'http_5xx_rate': metrics['http_5xx'] / total,
                'http_4xx_rate': metrics['http_4xx'] / total,
                'success_rate': metrics['http_2xx'] / total,
                'avg_cpu': metrics['cpu_usage_sum'] / total,
                'avg_memory': metrics['memory_usage_sum'] / total,
                'unique_error_count': len(metrics['unique_errors']),
                'total_requests': total
            }
        return result

def lambda_handler(event, context):
    """Handler principal de Lambda"""
    extractor = FeatureExtractor()
    
    # Procesar registros de Kinesis
    for record in event['Records']:
        try:
            # Decodificar datos de Kinesis
            payload = base64.b64decode(record['kinesis']['data'])
            log_entry = json.loads(payload)
            extractor.extract(log_entry)
        except Exception as e:
            print(f"Error processing record: {e}")
            continue
    
    # Calcular features agregadas
    aggregated = extractor.compute_aggregated_features()
    
    # Guardar en S3
    if aggregated:
        save_to_s3(aggregated)
    
    return {
        'statusCode': 200,
        'body': json.dumps(f'Processed {len(event["Records"])} records')
    }

def save_to_s3(features):
    """Guarda features en S3 particionado por fecha"""
    for window_key, feature_vector in features.items():
        dt = datetime.fromisoformat(window_key)
        s3_key = f"features/year={dt.year}/month={dt.month:02d}/day={dt.day:02d}/{window_key}.json"
        
        s3_client.put_object(
            Bucket='logs-features-bucket',
            Key=s3_key,
            Body=json.dumps(feature_vector),
            ContentType='application/json'
        )
```

### 3.4 AWS Glue ETL

#### 3.4.1 Job de Preparación de Datos

```python
import sys
from awsglue.transforms import *
from awsglue.utils import getResolvedOptions
from pyspark.context import SparkContext
from awsglue.context import GlueContext
from awsglue.job import Job
from pyspark.sql.functions import *
from pyspark.sql.window import Window

args = getResolvedOptions(sys.argv, ['JOB_NAME', 'SOURCE_BUCKET', 'TARGET_BUCKET'])

sc = SparkContext()
glueContext = GlueContext(sc)
spark = glueContext.spark_session
job = Job(glueContext)
job.init(args['JOB_NAME'], args)

# Leer features de S3
df = spark.read.json(f"s3://{args['SOURCE_BUCKET']}/features/*/*/*/*/")

# Limpieza y transformación
df_clean = df.filter(col("total_requests") > 10)  # Filtrar ventanas con poco tráfico

# Calcular features adicionales
window_spec = Window.orderBy("timestamp").rowsBetween(-12, 0)  # 1 hora (12 ventanas de 5 min)

df_enriched = df_clean.withColumn(
    "error_rate_trend", 
    avg("error_rate").over(window_spec)
).withColumn(
    "latency_trend",
    avg("avg_latency").over(window_spec)
).withColumn(
    "error_rate_spike",
    when(col("error_rate") > col("error_rate_trend") * 2, 1).otherwise(0)
)

# Normalización
from pyspark.ml.feature import StandardScaler, VectorAssembler

feature_cols = [
    'error_rate', 'avg_latency', 'max_latency', 
    'http_5xx_rate', 'http_4xx_rate', 'success_rate',
    'avg_cpu', 'avg_memory', 'unique_error_count',
    'error_rate_trend', 'latency_trend'
]

assembler = VectorAssembler(inputCols=feature_cols, outputCol="features_vector")
df_vector = assembler.transform(df_enriched)

scaler = StandardScaler(inputCol="features_vector", outputCol="scaled_features")
scaler_model = scaler.fit(df_vector)
df_scaled = scaler_model.transform(df_vector)

# Guardar dataset de entrenamiento
output_path = f"s3://{args['TARGET_BUCKET']}/training-data/"
df_scaled.write.mode("overwrite").parquet(output_path)

job.commit()
```

#### 3.5.2 Script de Inferencia Personalizado

```python
# inference.py
import json
import numpy as np

def model_fn(model_dir):
    """Carga el modelo"""
    import pickle
    with open(f'{model_dir}/model.pkl', 'rb') as f:
        model = pickle.load(f)
    return model

def input_fn(request_body, content_type):
    """Procesa input"""
    if content_type == 'application/json':
        data = json.loads(request_body)
        return np.array(data['features']).reshape(1, -1)
    raise ValueError(f"Unsupported content type: {content_type}")

def predict_fn(input_data, model):
    """Realiza predicción"""
    anomaly_score = model.score_samples(input_data)[0]
    
    # Calcular probabilidad de anomalía
    threshold = -0.5  # Ajustar según validación
    is_anomaly = anomaly_score < threshold
    
    return {
        'anomaly_score': float(anomaly_score),
        'is_anomaly': bool(is_anomaly),
        'confidence': float(abs(anomaly_score))
    }

def output_fn(prediction, accept):
    """Formatea output"""
    if accept == 'application/json':
        return json.dumps(prediction), accept
    raise ValueError(f"Unsupported accept type: {accept}")
```

### 3.6 Lambda Alert Processing

#### 3.6.1 Código de Procesamiento de Alertas

```python
import json
import boto3
import os
from datetime import datetime

sagemaker_runtime = boto3.client('sagemaker-runtime')
ses_client = boto3.client('ses')
dynamodb = boto3.resource('dynamodb')

ENDPOINT_NAME = os.environ['SAGEMAKER_ENDPOINT']
ALERT_TABLE = os.environ['ALERT_TABLE']
EMAIL_FROM = os.environ['EMAIL_FROM']
EMAIL_TO = os.environ['EMAIL_TO'].split(',')

table = dynamodb.Table(ALERT_TABLE)

def lambda_handler(event, context):
    """Procesa features y genera alertas"""
    
    # Obtener features del evento
    features = extract_features_from_event(event)
    
    # Invocar modelo de SageMaker
    response = sagemaker_runtime.invoke_endpoint(
        EndpointName=ENDPOINT_NAME,
        ContentType='application/json',
        Body=json.dumps({'features': features})
    )
    
    result = json.loads(response['Body'].read().decode())
    
    # Verificar si es anomalía
    if result['is_anomaly']:
        alert_id = generate_alert(result, features)
        send_email_alert(alert_id, result, features)
        
        return {
            'statusCode': 200,
            'body': json.dumps({
                'alert_generated': True,
                'alert_id': alert_id,
                'anomaly_score': result['anomaly_score']
            })
        }
    
    return {
        'statusCode': 200,
        'body': json.dumps({'alert_generated': False})
    }

def extract_features_from_event(event):
    """Extrae vector de features del evento"""
    # Leer últimas features agregadas de S3
    s3_client = boto3.client('s3')
    bucket = os.environ['FEATURES_BUCKET']
    
    # Obtener archivo más reciente
    now = datetime.utcnow()
    key = f"features/year={now.year}/month={now.month:02d}/day={now.day:02d}/"
    
    response = s3_client.list_objects_v2(Bucket=bucket, Prefix=key)
    latest_file = sorted(response['Contents'], key=lambda x: x['LastModified'])[-1]
    
    obj = s3_client.get_object(Bucket=bucket, Key=latest_file['Key'])
    features_data = json.loads(obj['Body'].read())
    
    # Construir vector de features
    feature_vector = [
        features_data['error_rate'],
        features_data['avg_latency'],
        features_data['max_latency'],
        features_data['http_5xx_rate'],
        features_data['http_4xx_rate'],
        features_data['success_rate'],
        features_data['avg_cpu'],
        features_data['avg_memory'],
        features_data['unique_error_count']
    ]
    
    return feature_vector

def generate_alert(result, features):
    """Genera registro de alerta en DynamoDB"""
    alert_id = f"alert-{datetime.utcnow().isoformat()}"
    
    table.put_item(
        Item={
            'alert_id': alert_id,
            'timestamp': datetime.utcnow().isoformat(),
            'anomaly_score': str(result['anomaly_score']),
            'confidence': str(result['confidence']),
            'features': json.dumps(features),
            'status': 'OPEN',
            'ttl': int(datetime.utcnow().timestamp()) + (30 * 24 * 60 * 60)  # 30 días
        }
    )
    
    return alert_id
```

```python
import boto3
import pandas as pd
import json

s3_client = boto3.client('s3')

def lambda_handler(event, context):
    """Valida calidad de datos de entrenamiento"""
    
    bucket = event['bucket']
    key = event['key']
    
    # Leer datos
    obj = s3_client.get_object(Bucket=bucket, Key=key)
    df = pd.read_parquet(obj['Body'])
    
    # Validaciones
    quality_checks = {
        'row_count': len(df),
        'null_percentage': df.isnull().sum().sum() / (len(df) * len(df.columns)),
        'duplicate_percentage': df.duplicated().sum() / len(df),
        'feature_variance': df.var().mean(),
        'outlier_percentage': calculate_outliers(df)
    }
    
    # Calcular score de calidad
    quality_score = calculate_quality_score(quality_checks)
    
    return {
        'statusCode': 200,
        'quality_score': quality_score,
        'checks': quality_checks,
        'passed': quality_score > 0.8
    }

def calculate_outliers(df):
    """Calcula porcentaje de outliers usando IQR"""
    outliers = 0
    for col in df.select_dtypes(include=['float64', 'int64']).columns:
        Q1 = df[col].quantile(0.25)
        Q3 = df[col].quantile(0.75)
        IQR = Q3 - Q1
        outliers += ((df[col] < (Q1 - 1.5 * IQR)) | (df[col] > (Q3 + 1.5 * IQR))).sum()
    
    return outliers / (len(df) * len(df.columns))

def calculate_quality_score(checks):
    """Calcula score agregado de calidad"""
    score = 1.0
    
    # Penalizar por nulls
    score -= checks['null_percentage'] * 0.5
    
    # Penalizar por duplicados
    score -= checks['duplicate_percentage'] * 0.3
    
    # Penalizar por baja varianza
    if checks['feature_variance'] < 0.1:
        score -= 0.2
    
    # Penalizar por muchos outliers
    if checks['outlier_percentage'] > 0.1:
        score -= 0.2
    
    return max(0, score)
```

```python
class DriftDetector:
    def __init__(self, baseline_stats):

    def detect_drift(self, current_data):

            drift_scores[feature] = {
                'ks_statistic': ks_stat,
                'p_value': p_value,
                'js_divergence': js_div,
                'has_drift': p_value < 0.05 or js_div > 0.1
            }
        
        # Publicar métricas
        self._publish_metrics(drift_scores)
        
        return drift_scores
    
    def _jensen_shannon_divergence(self, p, q):
        """Calcula JS divergence entre dos distribuciones"""
        p_hist, _ = np.histogram(p, bins=50, density=True)
        q_hist, _ = np.histogram(q, bins=50, density=True)
        
        # Normalizar
        p_hist = p_hist / p_hist.sum()
        q_hist = q_hist / q_hist.sum()
        
        m = 0.5 * (p_hist + q_hist)
        return 0.5 * (stats.entropy(p_hist, m) + stats.entropy(q_hist, m))
    
    def _publish_metrics(self, drift_scores):
        """Publica métricas de drift a CloudWatch"""
        for feature, scores in drift_scores.items():
            cloudwatch.put_metric_data(
                Namespace='ML/DataDrift',
                MetricData=[
                    {
                        'MetricName': 'JSDivergence',
                        'Value': scores['js_divergence'],
                        'Unit': 'None',
                        'Dimensions': [
                            {'Name': 'Feature', 'Value': feature}
                        ]
                    }
                ]
            )
```

```python
def system_health_check():

    functions = ['log-feature-extractor', 'alert-processor']

            EndTime=datetime.utcnow(),
            Period=3600,
            Statistics=['Sum']
        )
        
        error_count = errors['Datapoints'][0]['Sum'] if errors['Datapoints'] else 0
        
        report['checks'][f'lambda_{func_name}'] = {
            'status': func['Configuration']['State'],
            'errors_last_hour': error_count,

        }
```

```python
def optimize_kinesis_shards():
    """Optimiza número de shards basado en utilización"""
    
    # Obtener métricas de utilización
    metrics = cloudwatch.get_metric_statistics(
        Namespace='AWS/Kinesis',
        MetricName='IncomingBytes',
        Dimensions=[{'Name': 'StreamName', 'Value': 'app-logs-stream'}],
        StartTime=datetime.utcnow() - timedelta(days=7),
        EndTime=datetime.utcnow(),
        Period=3600,
        Statistics=['Average', 'Maximum']
    )
    
    # Calcular utilización promedio
    avg_bytes_per_sec = sum(d['Average'] for d in metrics['Datapoints']) / len(metrics['Datapoints'])
    max_bytes_per_sec = max(d['Maximum'] for d in metrics['Datapoints'])
    
    # Cada shard soporta 1 MB/s
    required_shards_avg = int(avg_bytes_per_sec / (1024 * 1024)) + 1
    required_shards_max = int(max_bytes_per_sec / (1024 * 1024)) + 1
    
    # Agregar 20% de buffer
    optimal_shards = int(required_shards_max * 1.2)
    
    # Obtener shard count actual
    stream = kinesis.describe_stream(StreamName='app-logs-stream')
    current_shards = len(stream['StreamDescription']['Shards'])
    
    print(f"Current shards: {current_shards}")
    print(f"Optimal shards: {optimal_shards}")
    print(f"Potential savings: ${(current_shards - optimal_shards) * 0.015 * 730:.2f}/month")
    
    # Ajustar si la diferencia es significativa
    if abs(current_shards - optimal_shards) > 10:
        kinesis.update_shard_count(
            StreamName='app-logs-stream',
            TargetShardCount=optimal_shards,
            ScalingType='UNIFORM_SCALING'
        )
```

```python
def optimize_lambda_configuration():
    """Optimiza configuración de Lambda para costo/performance"""
    
    lambda_client = boto3.client('lambda')
    cloudwatch = boto3.client('cloudwatch')
    
    function_name = 'log-feature-extractor'
    
    # Obtener métricas de uso de memoria

        Namespace='AWS/Lambda',
        MetricName='MaxMemoryUsed',
        Dimensions=[{'Name': 'FunctionName', 'Value': function_name}],
        StartTime=datetime.utcnow() - timedelta(days=7),
        EndTime=datetime.utcnow(),
        Period=3600,
        Statistics=['Maximum', 'Average']
    )
    
    max_memory_used = max(d['Maximum'] for d in memory_metrics['Datapoints'])
    avg_memory_used = sum(d['Average'] for d in memory_metrics['Datapoints']) / len(memory_metrics['Datapoints'])
    
    # Obtener configuración actual
    func_config = lambda_client.get_function_configuration(FunctionName=function_name)
    current_memory = func_config['MemorySize']
    
    # Calcular memoria óptima (max usado + 20% buffer)
    optimal_memory = int((max_memory_used * 1.2) / 128) * 128  # Redondear a múltiplo de 128
    
    print(f"Current memory: {current_memory} MB")
    print(f"Average used: {avg_memory_used:.0f} MB")
    print(f"Max used: {max_memory_used:.0f} MB")
    print(f"Optimal memory: {optimal_memory} MB")
    
    # Calcular ahorro potencial
    # Costo = (memory/1024) * duration * invocations * $0.0000166667
    duration_metrics = cloudwatch.get_metric_statistics(
        Namespace='AWS/Lambda',
        MetricName='Duration',
        Dimensions=[{'Name': 'FunctionName', 'Value': function_name}],
        StartTime=datetime.utcnow() - timedelta(days=30),
        EndTime=datetime.utcnow(),
        Period=2592000,  # 30 días
        Statistics=['Sum', 'SampleCount']
    )
    
    total_duration_ms = duration_metrics['Datapoints'][0]['Sum']
    total_invocations = duration_metrics['Datapoints'][0]['SampleCount']
    
    current_cost = (current_memory / 1024) * (total_duration_ms / 1000) * 0.0000166667
    optimal_cost = (optimal_memory / 1024) * (total_duration_ms / 1000) * 0.0000166667
    
    print(f"Current monthly cost: ${current_cost:.2f}")
    print(f"Optimal monthly cost: ${optimal_cost:.2f}")
    print(f"Potential savings: ${current_cost - optimal_cost:.2f}/month")
    
    # Actualizar si hay ahorro significativo
    if optimal_memory < current_memory and (current_cost - optimal_cost) > 10:
        lambda_client.update_function_configuration(
            FunctionName=function_name,
            MemorySize=optimal_memory
        )
```

```python
        },
```

```python
        Metrics=['UnblendedCost'],
        GroupBy=[

            'Tags': {
                'Key': 'Project',
                'Values': ['LogAnalytics']
            }
        }
    )
    
    # Procesar resultados
    costs = {}
    total_cost = 0
    
    for result in response['ResultsByTime']:
        for group in result['Groups']:
            service = group['Keys'][0]
            cost = float(group['Metrics']['UnblendedCost']['Amount'])
            costs[service] = cost
            total_cost += cost
    
    # Generar reporte
    print("=" * 60)
    print(f"Cost Report: {start_date} to {end_date}")
    print("=" * 60)
    
    for service, cost in sorted(costs.items(), key=lambda x: x[1], reverse=True):

        print(f"{service:30} ${cost:8.2f} ({percentage:5.1f}%)")
    
    print("=" * 60)
    print(f"{'TOTAL':30} ${total_cost:8.2f}")
    print("=" * 60)
    
    # Comparar con mes anterior
    prev_start = start_date - timedelta(days=30)
    prev_end = start_date
    
    prev_response = ce.get_cost_and_usage(
        TimePeriod={
            'Start': prev_start.isoformat(),
            'End': prev_end.isoformat()

        Metrics=['UnblendedCost']

    # Proyección
    days_in_month = (end_date - start_date).days
    daily_avg = total_cost / days_in_month
    projected_monthly = daily_avg * 30
```

```python
import boto3
import json
from datetime import datetime

def trace_log_processing(log_id):
    """Traza el procesamiento de un log específico"""
    
    print(f"Tracing log ID: {log_id}")
    print("=" * 60)
    
    # 1. Buscar en Kinesis
    kinesis = boto3.client('kinesis')
    
    shard_iterator = kinesis.get_shard_iterator(
        StreamName='app-logs-stream',
        ShardId='shardId-000000000000',
        ShardIteratorType='TRIM_HORIZON'
    )['ShardIterator']
    
    found_in_kinesis = False
    while shard_iterator:
        records = kinesis.get_records(ShardIterator=shard_iterator)
        
        for record in records['Records']:
            data = json.loads(record['Data'])
            if data.get('log_id') == log_id:
                print(f"✓ Found in Kinesis")
                print(f"  Timestamp: {record['ApproximateArrivalTimestamp']}")
                print(f"  Sequence: {record['SequenceNumber']}")
                found_in_kinesis = True
                break
        
        if found_in_kinesis or not records['NextShardIterator']:
            break
        
        shard_iterator = records['NextShardIterator']
    
    # 2. Buscar en CloudWatch Logs (Lambda)
    logs = boto3.client('logs')
    
    response = logs.filter_log_events(
        logGroupName='/aws/lambda/log-feature-extractor',
        startTime=int((datetime.utcnow().timestamp() - 3600) * 1000),
        filterPattern=f'"{log_id}"'
    )
    
    if response['events']:
        print(f"✓ Processed by Lambda")
        for event in response['events']:
            print(f"  Timestamp: {datetime.fromtimestamp(event['timestamp']/1000)}")
            print(f"  Message: {event['message'][:100]}...")
    
    # 3. Buscar en S3
    s3 = boto3.client('s3')
    
    # Buscar en features
    now = datetime.utcnow()
    prefix = f"features/year={now.year}/month={now.month:02d}/day={now.day:02d}/"
    
    response = s3.list_objects_v2(
        Bucket='logs-features-ACCOUNT',
        Prefix=prefix
    )
    
    found_in_s3 = False
    for obj in response.get('Contents', []):
        content = s3.get_object(Bucket='logs-features-ACCOUNT', Key=obj['Key'])
        data = json.loads(content['Body'].read())
        
        if log_id in str(data):
            print(f"✓ Found in S3 features")
            print(f"  Key: {obj['Key']}")
            print(f"  Last Modified: {obj['LastModified']}")
            found_in_s3 = True
            break
    
    # 4. Verificar si generó alerta
    dynamodb = boto3.resource('dynamodb')
    table = dynamodb.Table('anomaly-alerts')
    
    response = table.scan(
        FilterExpression='contains(#data, :log_id)',
        ExpressionAttributeNames={'#data': 'features'},
        ExpressionAttributeValues={':log_id': log_id}
    )
```

|---------|------------|
| **Anomaly Score** | Valor numérico que indica qué tan anómalo es un punto de datos. Valores más negativos indican mayor anomalía. |

| **Shard** | Unidad de capacidad en Kinesis Data Streams. Cada shard soporta 1 MB/s de entrada. |
| **Drift** | Cambio en la distribución de datos a lo largo del tiempo que puede afectar la precisión del modelo. |
| **Cold Start** | Retraso inicial cuando una función Lambda se invoca por primera vez o después de inactividad. |
| **Endpoint** | Instancia desplegada de un modelo de SageMaker que acepta peticiones de inferencia. |
